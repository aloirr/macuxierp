# T-0025 — coord.mjs: gravar recado por git quando a API do GitHub recusar a escrita na nuvem

## Objetivo
Na sessão da nuvem, o proxy recusa a escrita pela API do GitHub (HTTP 403 em `git/blobs`, `git/trees`, `git/commits`, `git/refs`). A leitura funciona. Na abertura, o recado foi gravado com `MACUXI_RECADOS=local`, a partir de um clone do `aloirr/macuxierp-recados`, e enviado por `git push`. É governança: PR com `Agente: alexandre`.

## Critérios de aceite
1. Com o 403 de escrita, `enviar` e `lido` caem para clone raso + commit + push (`--ff-only`, sem force), sem perder o formato.
2. Testes do `coord-recados.test.mjs` cobrem o caminho por git.
3. Doc 07 e ADR 0004 atualizados.
